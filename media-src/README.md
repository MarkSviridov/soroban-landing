# media-src/

Исходные медиафайлы от заказчика — **не входят в сборку** (`dist/`).

Лежат вне `public/`, поэтому Astro их не копирует и на сайт они не попадают.
Здесь хранятся оригиналы, из которых делаются оптимизированные версии в `public/`.

| Файл                        | Что это                               | Оптимизированная версия                                                  |
| --------------------------- | ------------------------------------- | ------------------------------------------------------------------------ |
| `videos/VSLPlaceholder.MOV` | оригинал VSL-видео (720×1280, ~42 МБ) | `public/videos/vsl-soroban.mp4` + `public/videos/vsl-soroban-poster.jpg` |

Команды перекодирования — в `public/videos/README.md`.
