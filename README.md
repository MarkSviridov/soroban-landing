# SOROBAN — лендинг (Кишинёв)

Конверсионный лендинг школы ментальной арифметики SOROBAN.
Главная цель — заявка родителя на **бесплатный пробный урок** для ребёнка 5–12 лет.

## Стек

- [Astro 5](https://astro.build/) — статическая сборка, минимум JS
- [Tailwind CSS v4](https://tailwindcss.com/) — конфиг через `@theme` в `src/styles/global.css`
- TypeScript
- `astro-icon`, `@astrojs/sitemap`
- Prettier + ESLint

## Команды

```bash
npm install       # установка зависимостей
npm run dev       # локальный сервер (http://localhost:4321)
npm run build     # прод-сборка в dist/
npm run preview   # предпросмотр собранного
npm run check     # проверка типов (astro check)
npm run format    # форматирование Prettier
npm run lint      # ESLint + проверка форматирования
```

## Где править контент

| Все тексты интерфейса                          | `src/content/site.ts` (`ru`)   |

## Локализация (RU / RO)

- **RU** — `https://soroban.digital/` (`src/pages/index.astro`, `src/pages/privacy.astro`).
- **RO** — `https://soroban.digital/ro/` (`src/pages/ro/index.astro`, `src/pages/ro/privacy.astro`).
- Весь текст интерфейса — в `src/content/site.ts`: `site.ru` и `site.ro` (тип `LocaleContent`).
- Компоненты общие. Локаль определяется по URL: `getLocale(Astro.url)` → `ru | ro`
  (`/ro`, `/ro/...` → `ro`, всё остальное → `ru`). Клиентский `form.client.ts` берёт
  локаль из `document.documentElement.lang`.
- `BaseLayout` выставляет `<html lang>`, `og:locale`, `<link rel="alternate" hreflang>`
  (`ru` / `ro` / `x-default`), canonical — по текущему пути.
- Переключатель языка — `src/components/layout/LangSwitch.astro` (в шапке); без
  авто-редиректа по языку браузера.
- `@astrojs/sitemap` настроен с `i18n` — в `sitemap-0.xml` есть все 4 URL с `xhtml:link`.
- RO-переводы — живой румынский для Республики Молдова (не дословный перевод).
  Сектора Кишинёва: Centru / Botanica / Ciocana / Buiucani. Термины: «lecție de probă
  gratuită», «aritmetică mentală», «profesor», «sediile școlii».

## Форма заявки

**Форма пока не отправляет данные никуда** (нет Telegram / email / Google Sheets / CRM).
Реализован только mock-submit для демонстрации интерфейса: имитация задержки и
состояний `отправка → успех → ошибка`. Канал получения заявок выбирается позже —
тогда правится единственная функция отправки, вёрстка и логика состояний не меняются.

Поля формы: имя родителя, телефон, возраст ребёнка, удобный район
(Центр / Ботаника / Чоканы / Буюканы / Онлайн / Не знаю, подскажите),
язык занятий (русский / румынский), формат (офлайн / онлайн),
согласие на обработку персональных данных.

## Отзывы (Google Карты)

Скриншоты в `public/images/reviews/` (оригиналы) и `public/images/optimized/reviews/`
(WebP, подключены в секции `Testimonials`) взяты из публичного профиля школы в
Google Картах. Тексты, авторы, даты и оценки не изменялись.

**Перед публикацией сайта необходимо подтвердить, что школа вправе использовать
эти скриншоты в рекламном лендинге.**

Заметки по содержимому (ничего не ретушировалось — решение за школой):

- `review-03` — имя автора на скриншоте содержит суффикс `_10.07` (похоже на дату);
- `review-08` (2-й отзыв) — автор указывает возраст своих детей («8 лет и 11 лет»);
- `review-09` (2-й отзыв) — автор называет имя ребёнка в тексте отзыва;
- в `review-03, 05, 06, 07, 08, 09, 10` часть отзывов свёрнута самим интерфейсом
  Google («Ещё» / «Подробнее» / «Более») — текст виден не полностью. При
  необходимости заменить на скриншоты с раскрытым текстом.

Прямой ссылки на профиль отзывов в Google пока нет в `src/consts.ts`
(`GOOGLE_REVIEWS_URL` пуст), поэтому кнопка «Смотреть отзывы в Google» не выводится.

## Гарантия результата

На лендинге нет утверждений о гарантии результата. Формулировка школой не
утверждена — поле-заглушка удалено из `src/content/site.ts`. Когда текст
согласуют, добавить поле в `LocaleContent` (для обеих локалей) и отдельную секцию.

## Чего на лендинге сознательно нет

Цена (по требованию заказчика), таймеры обратного отсчёта, обещания «улучшить
интеллект», неподтверждённые цифры, выдуманные отзывы, выдуманные имена/фото
преподавателей и юридические реквизиты.
