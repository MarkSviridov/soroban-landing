# Изображения

Папки под реальные ассеты. Пока пусто — компоненты используют заглушки.

| Папка     | Что кладём                                           | Где подключается            |
| --------- | ---------------------------------------------------- | --------------------------- |
| `logo/`   | Логотип SOROBAN (SVG, при наличии — светлый вариант) | шапка, футер                |
| `photos/` | Реальные фото занятий, детей, офисов                 | Hero, «Как проходят», офисы |
| `app/`    | Скриншоты приложения SoroboomAR                      | секция SoroboomAR           |
| `video/`  | Постер и файл VSL (или используем embed)             | секция «Видео о занятиях»   |
| `og/`     | `og-default.png` (1200×630) для соцсетей             | `BaseLayout.astro`          |

Форматы: фото — JPG/WebP, логотип — SVG, скриншоты — PNG/WebP.
